# Archivos del juego pendientes de incorporación

La conexión de GitHub permite escribir archivos de texto, pero en esta sesión no permite leer directamente los archivos binarios guardados en el entorno de generación para transferirlos al repositorio. Por eso **los HTML y PNG todavía no están publicados aquí**.

## Versión estable y de desarrollo
- `index.html` ← `julieta_va_al_cole_personajes_integrados.html` (base de referencia).
- `dev/animacion.html` ← `JULIETA_VA_AL_COLE_sprites_limpios.html` (última prueba).
- `backups/` ← HTML de v10, animación inicial, pasos alternos y animación corregida.
- `assets/personajes/` ← PNG de Julieta, Isaías, Nacho y 4 fotogramas nuevos.

## Cómo incorporar
1. Descargar el ZIP de copia de seguridad facilitado en el chat.
2. Descomprimirlo.
3. En GitHub, entrar al repositorio y usar **Add file → Upload files** para incorporar los archivos descomprimidos, manteniendo sus rutas.
4. Confirmar los cambios (Commit changes).
5. Verificar en GitHub que se muestran los HTML y PNG.

**No eliminar ni sobrescribir archivos antiguos** hasta verificar la nueva versión.
